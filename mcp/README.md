# ilham-mcp

A small, **discovery-only** [MCP](https://modelcontextprotocol.io) server for the
tools on <https://ilham.dev>. It lets an assistant answer "is there a tool for
this?" and hand back a link — it never runs anything.

It is a standalone Cloudflare Worker. The Hugo site does not depend on it, and it
has no database: it reads the public registry at
<https://ilham.dev/tools/tools.json> and caches it at the edge for an hour.

## Tools exposed

| MCP tool       | What it does                                                        |
| -------------- | ------------------------------------------------------------------- |
| `list_tools`   | List every tool, optionally filtered by category.                   |
| `search_tools` | Find tools from a plain-language need ("check which process uses a port"). |
| `get_tool`     | Full record for one tool: docs URL, keywords, use cases, examples.  |

Plus a tiny REST face for humans and curl: `/api/tools`, `/api/search?q=`,
`/api/tool/:id`, and `/health`.

## Why discovery only

Every tool on ilham.dev runs entirely in the browser. Nothing is uploaded, and
there is no server that could run a command for you. An MCP server that could
*execute* those tools would need to move that work server-side, which would break
that promise. So this server only reads the registry.

## Deploy

```bash
cd mcp
npm install
npx wrangler login          # once
npm run typecheck
npm run deploy
```

Then attach the domain. Either uncomment the route in `wrangler.toml`:

```toml
routes = [{ pattern = "mcp.ilham.dev", custom_domain = true }]
```

or add it in the Cloudflare dashboard under **Workers → ilham-mcp → Settings →
Domains & Routes**. Either way you need `ilham.dev` on the same Cloudflare
account.

## Verify

```bash
curl https://mcp.ilham.dev/health
curl 'https://mcp.ilham.dev/api/search?q=disk%20full'
curl -s https://mcp.ilham.dev/mcp -H 'content-type: application/json' -d '{
  "jsonrpc": "2.0", "id": 1, "method": "tools/list"
}'
```

## Connect a client

```jsonc
// Claude Desktop / most MCP clients
{
  "mcpServers": {
    "ilham-tools": { "url": "https://mcp.ilham.dev/mcp" }
  }
}
```

## How it stays in sync

`tools.json` is generated by the Hugo build from `data/tools.yaml`,
`data/tool-guides.yaml` and `data/tool-ai.yaml`. Add or rename a tool on the site
and this server picks it up within an hour, with no redeploy and no code change.

## Files

```
wrangler.toml   Worker config (no bindings, no migrations)
src/index.ts    MCP server + REST endpoints
src/registry.ts fetch, cache, brief, byCategory, search
```
