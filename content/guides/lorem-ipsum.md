**Placeholder text** lets you test how a layout looks before real copy is ready. [Lorem Ipsum](/tools/lorem-ipsum/) generates sample words, sentences, or paragraphs; the text is not meant to be published as finished writing.

## Fill a small layout

Set **Amount** to `3`, **Unit** to **Words**, and leave **Start with “Lorem ipsum…”** checked. Choose **Generate**. **Output** should read `Lorem ipsum dolor`. **Copy** takes the current output; **Download** saves `lorem.txt`. Uncheck the classic option and generate again: the three words now come from a random word pool, so the exact result varies.

If you switch to **Paragraphs** with the classic option still on, the tool adds the classic opening as an **extra paragraph** before the requested number of generated paragraphs. If you need exactly three paragraphs, uncheck it. The output stays in the browser.

## Where your input goes

Processing runs in your browser. The tool does not upload your input to ilham.dev.
