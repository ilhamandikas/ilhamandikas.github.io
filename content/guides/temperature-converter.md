Celsius, Fahrenheit, and Kelvin are three scales for describing temperature. The **same** temperature gets a different number on each scale. [Temperature Converter](/tools/temperature-converter/) shows all three numbers together.

## Convert boiling water

Choose **Celsius (°C)** under **Unit**, then type `100` in **Temperature**. In **All units**, you should see `100 °C`, `212 °F`, and `373.15 K`. These are three ways to describe the same temperature, not three different temperatures.

Now choose **Fahrenheit (°F)** and replace the input with `212`. You should see `100 °C` again. The tool reads the number according to the **Unit** you selected; changing the unit without changing the number asks a different question. Kelvin uses `K`, not a degree symbol.

## If you see an error

The input must be a number. A temperature below absolute zero is rejected; on the Celsius scale, that is below `-273.15 °C`. If you meant a negative temperature, include the minus sign. Check both the number and its starting unit before copying a result. The tool rounds displayed values to two decimal places.

## Where your input goes

Processing runs in your browser. The tool does not upload your input to ilham.dev.

## Questions you might have

### Is there a temperature where Celsius and Fahrenheit agree?

Yes, at −40 degrees. It is the single point where the two scales cross.
