[Emoji Picker](/tools/emoji-picker/) has a **curated list** of emoji you can search by English name or keyword. It is not a complete Unicode emoji catalog, so a missing result does not mean an emoji does not exist.

## Find and copy one

Type `apple` into **Search emoji**. The grid should include a red apple (`🍎`). Select its button to copy the emoji character; the status reports what was copied. Paste it into a disposable text field to check it. Clear the search to browse again. Searching for a word that is not in the list leaves the grid empty and shows a zero count.

The browser copies the Unicode character, not a picture file. Appearance varies across operating systems and fonts. If you see an empty box after pasting, try a font or device that supports that character. Search and filtering run in this tab.

## Where your input goes

Processing runs in your browser. The tool does not upload your input to ilham.dev.
