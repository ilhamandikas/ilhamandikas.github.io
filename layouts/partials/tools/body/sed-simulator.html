Runs locally in your browser. Sample text is not uploaded or saved. This is a bounded sed simulation, not a shell or an in-place file editor.

ASCII/C-locale subset: literals, dot, anchors, bracket classes (including POSIX classes), groups, alternation, and greedy repetition. Groups do not expose captures: replacement backreferences such as \1, case conversions, arbitrary scripts, addresses, and multiline commands are not supported. Replacement supports &, \&, \\, \n, and \t.

Limits: 50,000 input characters, 5,000 lines, 5,000 characters per line, 256 pattern characters, finite repetition bounds up to 50, and bounded execution/output. This is not the full GNU sed implementation.
