Runs locally; inputs are not uploaded or saved. Generates commands for GNU tar on a POSIX shell. No files are read, archived, or extracted by this page.

The extraction directory must already exist. Inspect the listing first and use an empty destination without root privileges. An archive listing is not a security audit.

Base/destination directories must start with / or ./ and cannot contain .. segments or wildcards. Paths are literal: no tilde, variable, or shell-glob expansion. Excludes accept GNU tar patterns. Compression programs must be installed separately.
