Decoding is not verifying. The header and payload are plain base64url, so anyone can read or edit them — only the signature can show that the token has not been tampered with.






  
Check the signature

  

    
    
  

  

    
    
  

  
The algorithm is read from the token header. HS256, HS384 and HS512 take the shared secret as UTF-8 text; RS, PS and ES take a BEGIN PUBLIC KEY PEM. A valid signature proves the token was signed by the holder of that key — it does not prove the issuer is one you trust, and it says nothing about exp, aud or iss. Use this to debug a token, not as an authorisation check.
