Runs locally in your browser. Sample text is not uploaded or saved. Searches one virtual text input, not local files or directories.

ASCII/C-locale subset: literals, dot, anchors, bracket/POSIX classes, groups, alternation, and greedy repetition. Basic mode uses escaped groups, intervals, and GNU \+ \? \| operators. Backreferences, Perl regex, shorthand/word-boundary escapes, locale-specific matching, binary inputs, and recursive file searching are not supported.

Count takes precedence over matching-text output and ignores context. With -o, context can still separate groups; with -v, matching context rows can print match fragments. With zero context, -v plus -o produces no text. Limits: 50,000 input characters, 5,000 lines, 5,000 characters per line, 256 pattern characters, context up to 50, and bounded execution/output.
