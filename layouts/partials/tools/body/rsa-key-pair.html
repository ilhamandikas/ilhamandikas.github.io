Generate a key pair

The pair is generated in this page by the Web Crypto API. Nothing is uploaded, and nothing is stored — reload and it is gone.

Do these two keys match?

Both BEGIN PUBLIC KEY (SPKI) and BEGIN RSA PUBLIC KEY (PKCS#1) are accepted, and likewise BEGIN PRIVATE KEY and BEGIN RSA PRIVATE KEY. Only RSA keys can be checked — the matching test works by signing a throwaway message with the private key and asking the public key to verify it, and a signature never leaves this page.
