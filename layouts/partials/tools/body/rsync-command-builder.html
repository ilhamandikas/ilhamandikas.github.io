Runs locally; inputs are not uploaded or saved. Builds directory-transfer commands for rsync on a POSIX shell. It does not connect to SSH, inspect files, or transfer anything.

SSH mode uses -s to protect remote arguments and requires rsync 3.0+ on both sides. Remote paths must be absolute. IPv6 host notation, rsync daemons, and remote-to-remote copies are not supported. Identity paths are limited to letters, digits, underscores, hyphens, dots, and slashes.

Use /absolute or ./relative directory paths, without .. segments, wildcards, or tilde expansion. Source and destination are separate fields; do not paste user@host:path into either. The destination is always treated as a directory. Nothing here checks symlinks, overlapping trees, or missing mounts.

Command

      Dry-run first

      A dry-run still reads local paths and may connect and authenticate over SSH when you run it. Inspect its itemized output, including any *deleting entries. A later real run can differ if the filesystem changes.
