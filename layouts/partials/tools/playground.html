Runtime details {{ if $preparedInput }}

Interactive stdin installs a service worker scoped to /tools/ on its first Run. It answers only reserved input requests locally, without caching pages or persisting answers. If unavailable, use Prepared standard input. This is line-based input, not a shell or full terminal emulator.

{{ end }} {{ if eq $language "typescript" }}

The TypeScript 5.9.3 compiler downloads from jsDelivr on your first Run. This runner transpiles code and reports syntax errors; it does not perform semantic type-checking. Monaco's editor diagnostics are separate from execution. No Node.js or package imports.

{{ else if eq $language "python" }}

Pyodide 0.28.2 downloads its Python runtime and core standard library from jsDelivr on your first Run. Loading may take a moment. Use interactive terminal input, or prepare standard input before Run. No additional packages are installed automatically.

{{ else if eq $language "ruby" }}

The Ruby 3.4 WASI runtime (ruby.wasm 2.10.1) downloads from jsDelivr on Run. The binary is approximately 16 MiB before compression. Interactive terminal or prepared standard input; no gem installation or native OS processes. Runtime notices.

{{ else if or (eq $language "c") (eq $language "cpp") }}

The browsercc 0.1.1 Clang/LLD toolchain downloads from jsDelivr on the first Run — roughly 26 MiB compressed for clang.wasm, lld.wasm and the sysroot. Code is compiled to WebAssembly, then run in a fresh Worker. Use interactive terminal input, or prepare standard input before Run. C++ exceptions and threads are unavailable in this WASI toolchain. Runtime notices.

{{ else }}

JavaScript runs without downloading a language runtime.
