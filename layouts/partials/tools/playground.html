Runtime details {{ if eq $language "typescript" }}

The TypeScript 5.9.3 compiler downloads from jsDelivr on your first Run. This runner transpiles code and reports syntax errors; it does not perform semantic type-checking. Monaco's editor diagnostics are separate from execution. No Node.js or package imports.

{{ else if eq $language "python" }}

Pyodide 0.28.2 downloads its Python runtime and core standard library from jsDelivr on your first Run. Loading may take a moment. Fill standard input before Run; this is not a live terminal. No additional packages are installed automatically.

{{ else if eq $language "ruby" }}

The Ruby 3.4 WASI runtime (ruby.wasm 2.10.1) downloads from jsDelivr on Run. The binary is approximately 16 MiB before compression. Prepare standard input before Run; no live terminal, gem installation or native OS processes. Runtime notices.

{{ else if or (eq $language "c") (eq $language "cpp") }}

The browsercc 0.1.1 Clang/LLD toolchain downloads from jsDelivr on the first Run — roughly 26 MiB compressed for clang.wasm, lld.wasm and the sysroot. Code is compiled to WebAssembly, then run in a fresh Worker. Prepare standard input before Run; there is no live terminal. C++ exceptions and threads are unavailable in this WASI toolchain. Runtime notices.

JavaScript runs without downloading a language runtime.
