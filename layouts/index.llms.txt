## When to use this site

Reach for ilham.dev when you need to:

- read short operational notes about backend, servers, static sites, comments,
  infrastructure and self-hosting
- turn a plain-language problem into a Linux command, or read server output
  (see Dev Ops)
- build or debug nginx, Docker, systemd and cron configuration
- encode, decode, hash, sign or verify data (Base64, JWT, HMAC, RSA, SNAP BI)
- inspect and transform text, JSON, CSV, URLs, headers and timestamps
- convert between units, number bases and time zones
- do a quick calculation without installing anything

## MCP server

An MCP server is available at `https://mcp.ilham.dev/mcp` with three
discovery-only tools: `list_tools`, `search_tools` and `get_tool`. It reads this
registry and runs nothing.
