Each playground loads only its own runner, and a language runtime is fetched only when you Run. JavaScript needs no runtime download; TypeScript, Python, Ruby and the C/C++ Clang toolchain download assets from jsDelivr on Run. Code examples include arithmetic, prime numbers, searching, OOP and pyramid patterns. The tool does not save or upload your code, but compiled or interpreted snippets can make network requests.

These are browser environments, not complete desktop SDKs. Node.js APIs, arbitrary package imports, a live terminal, C/C++ exceptions and threads, and Ruby gems are not provided.
